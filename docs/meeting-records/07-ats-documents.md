# 07 ATS 문서팀 독립회의

## 10라운드 요약

1. 주장별 evidence_status·source·allowed_claim 필드 필요.
2. 직무명과 보조 검색어를 통일.
3. ATS 순서를 이름·연락처→요약→역량→경력→프로젝트→학력으로 고정.
4. 경력 bullet을 행사 운영·참가자·콘텐츠·디지털 축으로 재배열.
5. 수치는 자기보고·검증 대기.
6. UTF-8·HTML·YAML·PDF 한글 인코딩 별도 검증.
7. A4 1페이지와 텍스트 순서 필수 확인.
8. ATS 구조와 파스텔 시각품질 분리.
9. 직무별 변형은 headline·summary·순서만 승인 범위에서 허용.
10. SSOT 대조·증거·JD 매핑·인코딩·페이지·추출·웹 일치·사용자 승인 체크리스트 제안.

## 판정

실제 ATS 파서·JD·외부 컨설팅은 미실행.
