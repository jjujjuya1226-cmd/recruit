## 공통 보류 표현

다음 표현은 근거 감사 전 공개 문구로 사용하지 않습니다.

- 직접 만든 경험의 증거
- 검증된 성과
- 고객경험 혁신 결과
- End-to-End 성공 사례

## 실제 적용 순서

1. SSOT인 `resume.yaml`의 회사명 확인
2. 메인 웹·이력서·PDF 생성 원본의 회사명 및 대표 문구 동기화
3. 정적 링크·미디어·UTF-8 검사
4. 1페이지 PDF 재생성 및 텍스트·페이지 수 확인
5. diff 검토 후 commit
6. `git pull --rebase origin main` 후 `git push origin main`
7. GitHub Pages 배포본에서 대표 문구와 회사명 회귀 확인

이번 문서는 회의 결과만 기록하는 문서가 아니라, 회의 결과를 실제 산출물에 적용했는지 추적하는 기준 문서입니다.
