# 08 포트폴리오 편집팀 독립회의

## 10라운드 요약

1. 전체 위계를 Event Operations 중심으로 조정.
2. End-to-End·직접 구현·개선의 범위를 실제 역할에 제한.
3. 럭키드로우를 문제→대상→흐름→범위→현장 적용→근거로 재구성.
4. 수치는 자기보고·검증 대기.
5. 메인은 뉴스레터 대표 2장, 상세는 확보된 전체 자료.
6. 카드뉴스와 참가브랜드모집을 고객 여정·모집 캠페인으로 분리.
7. 모든 상세 페이지를 목적·문제·대상·역할·제작물·적용·결과·근거로 통일.
8. 영상·iframe·이미지·포커스 모바일 QA 필요.
9. PDF는 웹과 같은 축·순서로 요약.
10. 공개 상태를 SSOT·편집·브라우저 QA·외부검토·승인·공개로 분리.

## 판정

원본 자료 대조·채용자·모바일·브라우저 검증 미실행.
