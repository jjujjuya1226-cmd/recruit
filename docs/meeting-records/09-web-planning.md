# 09 웹 기획팀 독립회의

## 10라운드 요약

1. 첫 화면에 공식 직무명과 세 축을 고정.
2. 소개→역량→경력→포트폴리오를 명확한 정보 구조로 연결.
3. 영상은 현장성을 보조하고 카피·직무 인식을 우선.
4. 럭키드로우는 운영 문제의 디지털 전환으로 설명.
5. 뉴스레터 두 대표 이미지의 역할을 행사 소개·참여 안내로 구분.
6. 상세 페이지를 대상→문제→접점→결과물→근거로 통일.
7. 각 프로젝트와 실제 경력·행사·담당 범위를 연결.
8. 수치 옆 자기보고·검증 대기 라벨 고정.
9. 모바일·iframe·포커스·reduced-motion 체크리스트 필요.
10. 출시 기준을 5초 직무, 첫 스크롤 세 축, 클릭 없는 증거 이해, 모바일 정상 사용으로 확정.

## 판정

실제 사용자·HR·브라우저 검증 미실행.
