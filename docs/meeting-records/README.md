## 공통 판정

- 전략 방향: 국내 PCO·전시주최사·전시장 운영사 중심.
- 공식 포지셔닝 후보: `전시·MICE 현장 운영·고객경험 프로젝트 코디네이터`.
- 역량 위계: `Event Operations → Content & Customer Journey → Digital Operations Improvement`.
- `130%`, `2명→1명`: 원본 이력서 자기보고·검증 대기.
- 실제 JD 조사, 외부 HR 검토, ATS 파서, 실기기 QA: 독립회의에서는 미실행.
