# 01 최종 승인실 독립회의

## 10라운드 요약

1. SSOT: 수치에 검증 상태가 없어 자기보고·검증 대기로 고정.
2. 전략: 해외 B2B·구형 3트랙 혼재를 제거하고 국내 전시·MICE로 고정.
3. 채용자: 직무명·세 역량축을 첫 화면과 PDF 상단에 동시 노출.
4. 증거: 특별관·참가사 유치·정량 성과는 원자료 연결 전 보류.
5. 포지셔닝: 웹·PDF·포트폴리오의 직무명과 축을 통일.
6. 웹 경험: 스크롤 중심 구조와 뉴스레터 대표 이미지 2장 유지.
7. 디자인: 파스텔·온글잎박다현·Pretendard·영상·데모를 유지하되 실기기 검증 필요.
8. PDF: ATS·시각품질·한글 렌더를 별도 판정.
9. QA: 과거 2페이지 기록과 현재 1페이지 상태를 분리.
10. 거버넌스: 문서화·로컬 구현·외부 검증·사용자 승인을 별도 상태로 관리.

## 최종 권고

독립 내부 검토는 완료했지만 외부 HR·JD·브라우저 검증 전에는 최종 승인하지 않는다.
