# 13 접근성·QA팀 독립회의

## 10라운드 요약

1. lang·UTF-8 정적 확인, 배포 렌더 검증 필요.
2. Tab 순서·포커스·버튼·iframe 키보드 검증 필요.
3. 390px·768px·1440px 가로 오버플로·미디어 잘림 점검.
4. hero 영상 poster와 자동재생 fallback 필요.
5. iframe 장애 시 동일 기능 설명 제공.
6. 영상 자막·대체 텍스트·장면 설명 필요.
7. 중복 색상 토큰 정리와 대비 측정 필요.
8. fragment 링크와 파일 링크를 분리하는 검사 필요.
9. PDF 한글·인쇄·ATS 순서 독립 검사 필요.
10. 배포 회귀 체크리스트를 출시 기준으로 고정.
