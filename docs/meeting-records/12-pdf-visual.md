# 12 PDF 시각품질팀 독립회의

## 10라운드 요약

1. 제출용 PDF를 `류연주_1페이지_이력서.pdf`로 잠금; 9페이지 원본은 제출 금지.
2. 상단 이름·직무명·세 축의 5초 위계 필요.
3. PDF 파스텔 토큰과 resume.yaml 어두운 토큰 불일치.
4. 한글 글리프·줄바꿈·임베딩·추출 검증 필요.
5. 1페이지와 정보 밀도·최소 글자 크기 균형 필요.
6. 장식이 ATS 텍스트 순서를 방해하지 않게 제한.
7. 최신 전략 직무명으로 PDF 통일.
8. 수치는 자기보고·검증 대기 라벨로 과도한 강조 금지.
9. 웹과 PDF의 세 축·프로젝트 순서 일치.
10. 상태를 1페이지 로컬 확인·시각 QA·ATS·채용자 테스트로 분리.

## 판정

페이지 수는 로컬 확인했지만 외부 ATS·인쇄·채용자 시각 검증 미실행.
