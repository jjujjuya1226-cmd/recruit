# 류연주 커리어 운영조직 모델

## 목적

전시·MICE 현장 운영 경험을 기반으로, 고객경험 코디네이터로서의 채용 가능성을 높이는 폐루프 운영체계다. 경력 사실은 `resume.yaml`을 SSOT로 삼고, 전략·문서·웹·지원 결과가 서로 같은 메시지와 근거를 사용한다.

## 전체 조직

1. 최종 승인실: 경력 사실·수치·공개·지원·배포 승인
2. 커리어 전략본부: 목표 직무와 90일 실행 방향
3. 시장·JD 인텔리전스본부: 국내 전시·MICE 요구사항 조사
4. 채용 컨설팅본부: HR 독립심사와 전략 레드팀
5. 증거감사본부: 주장별 근거 상태 검증
6. 포지셔닝·브랜드본부: 고객경험 코디네이터 메시지 설계
7. 문서·PDF본부: ATS와 사람용 1페이지 PDF 제작
8. 포트폴리오 편집본부: 프로젝트별 케이스스터디와 미디어 근거
9. 웹 제품본부: 채용자 탐색 흐름과 정보구조
10. 웹 디자인·콘텐츠본부: 파스텔 디자인 시스템과 카피
11. 웹 개발·미디어본부: 정적 사이트·영상·인터랙션 구현
12. QA·접근성본부: PDF·웹·모바일·한글 렌더링 검수
13. 지원운영·결과학습본부: 지원 상태·면접·탈락 원인·전략 개선

## 상태 흐름

`evidence_locked → strategy_draft → consulting_review → strategy_approved → content_architecture → design_draft → qa_review → user_approval → published → outcome_learning`

## 승인 게이트

- 경력 사실·성과 수치 변경: 사용자 승인 필수
- 포트폴리오 공개 범위 변경: 사용자 승인 필수
- 외부 로그인·지원 제출·메시지 전송: 사용자 승인 필수
- PDF·웹 배포: QA 통과와 사용자 승인 필수
- 메쎄이상·엑스포럼: 지원 대상에서 제외

## 최종 커리어 가설

전시·MICE 현장의 참가자·참가사·운영 흐름을 이해하고, 콘텐츠와 디지털 운영 도구로 경험을 개선하는 프로젝트 코디네이터.

핵심 축은 `Event Operations`, `Content & Customer Journey`, `Digital Operations Improvement`다.
